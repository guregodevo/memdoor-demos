### NOTES

The core difficulty is that the "replace all x with y" operation is global and simultaneous, so the order of operations matters critically. If we need a→b and b→c, doing a→b first destroys the distinction between original a's and original b's. The problem reduces to: (1) verify the per-character mapping from S to T is well-defined (a function), and (2) count the minimum operations needed, which depends on the cycle structure of the resulting functional graph over at most 26 nodes.

The key structural insight: since each character maps to at most one target, the graph has out-degree ≤ 1 per node, so it decomposes into directed cycles with trees (chains) feeding into them, plus isolated fixed points. For the acyclic (chain) portions, operations can be performed in reverse topological order (sinks first), costing exactly one operation per edge. For a cycle of length k, we need k+1 operations (k normal steps plus one step to use a temporary letter outside the cycle). The total is |E| + C where |E| is the count of non-trivial edges and C is the number of cycles.

The impossibility condition beyond inconsistent mappings: if all 26 letters appear in S (so no "free" letter exists as a temporary) AND there is at least one cycle, the problem is impossible because no cycle can be broken. If at least one letter is absent from S, it can serve as a shared temporary for all cycles sequentially (after each cycle is resolved, the temporary is cleaned up by the final step).

The constraint N up to 2×10^5 is a red herring for the algorithmic core: the graph has at most 26 nodes, so all cycle detection is O(26). The only N-dependent work is building the mapping and checking consistency in O(N).

### NEXT

- **Approach 1 – Three-color DFS on functional graph:** Build the 26-node directed graph from the S→T mapping. Run a standard white/gray/black DFS to identify cycles. Count non-self edges as |E| and count each detected cycle as +1 to C. Check the "all 26 letters in S and C > 0" impossibility. Output |E| + C or -1. Pitfall: must only consider nodes that actually appear in S; a letter absent from S has no outgoing edge and cannot be part of a cycle.

- **Approach 2 – Kahn's algorithm / iterative leaf peeling:** Compute for each of the 26 letters whether it has an outgoing non-trivial edge. Iteratively remove nodes whose outgoing edge points to an already-removed (or absent) node. After the peeling process, any remaining nodes with outgoing edges form cycles. Count remaining edges as cycle edges. Total answer is (total non-trivial edges) + (number of cycles detected). Pitfall: must carefully handle the case where a node's target is a fixed point or absent—those nodes are "sinks" and get peeled first.

- **Approach 3 – Pointer chasing with a visited set (Floyd-style per component):** For each unvisited letter that appears in S, follow the mapping chain (c, f(c), f(f(c)), ...) marking visited. If you hit a previously-visited node that is part of the current chain, you found a cycle of the appropriate length. If you hit a fixed point or an absent letter, it's a chain. Sum up edges and cycle count. Pitfall: need to distinguish "visited in a prior traversal" from "visited in the current traversal" to correctly identify cycle boundaries; with only 26 nodes a simple set per-traversal suffices.

- **Approach 4 – Greedy simulation with a working string:** Maintain a mutable copy of S (length N). Repeatedly scan for a letter x whose current image in the working string already equals its target in T (i.e., x is "done" or doesn't need further changes), then for each remaining non-trivial mapping perform the replacement in an order that avoids conflicts. Count operations. Pitfall: O(N × 26) per step and hard to prove minimality; also, choosing the wrong "safe" operation could block progress. This approach is conceptually clearest but riskiest for correctness under time limits.

- **Approach 5 – Reduce to counting in a permutation decomposition:** Treat the mapping as a partial permutation (some letters absent). Decompose into cycles and transpositions using the standard permutation-cycle algorithm. The answer is (number of non-fixed points) + (number of non-trivial cycles), with the 26-letter impossibility check. This is essentially the same math as Approach 1 but framed in group-theoretic language; the implementation is nearly identical to a pointer-following loop over 26 elements. Pitfall: "partial" permutation (some letters have no image) means standard permutation algorithms need a guard for absent nodes.
