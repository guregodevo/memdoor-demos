### PLAN
The problem reduces to: (1) precompute the cost of making each window of size x have all equal elements (this cost is the sum of absolute deviations from the median of that window), and (2) select k non-overlapping windows minimizing total cost via DP. For step 1, use a sliding-window median maintained with two heaps (or a sorted multiset) plus running sums so all n-x+1 window costs are computed in O(n log x). For step 2, define dp[i][j] = min cost to place j non-overlapping x-subarrays within the first i positions; the recurrence is dp[i][j] = min(dp[i-1][j], dp[i-x][j-1] + cost[i-x]), giving O(n·k) time. Since k ≤ 15 and n ≤ 10⁵, this is well within limits. We must handle negative values and the constraint that subarrays cannot overlap.

### TASKS
- Implement a helper that, given `nums` and `x`, returns an array `cost` where `cost[i]` = sum of |nums[j] − median| for the window nums[i..i+x−1], using a two-heap sliding median with maintained left/right sums (O(n log x) total).
- Implement the DP: `dp[j]` = min cost to pick j non-overlapping subarrays from the prefix processed so far; iterate positions i from 0 to n−1, updating dp in reverse order of j (from k down to 1) so that `dp[j] = min(dp[j], dp[j−1] + cost[i])` when a subarray starts at i, with a guard ensuring the previous chosen subarray doesn't overlap (track or use a 2-D dp[i][j] with the recurrence dp[i][j] = min(dp[i−1][j], dp[i−x][j−1] + cost[i−x])).
- Write the final `solution.py` with the `Solution.minOperations` method that wires the cost computation and DP together, returning `dp[n][k]` (or the 1-D equivalent), and verify against both provided samples.
- Edge-case and complexity check: confirm correctness when k=1, when x equals n, when values are negative, and that total time is O(n·k + n·log x) and space is O(n·k) (or O(n) with rolling arrays); run a quick brute-force cross-check on small random inputs.
