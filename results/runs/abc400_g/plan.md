### PLAN
For each test case, the solution tries three different sort orders (by X, Y, or Z in descending order). For a given sort order, the key structural lemma is that the optimal K-pairing corresponds to selecting K non-overlapping adjacent pairs in that order. This reduces the subproblem to: given a sequence of N-1 adjacent-pair values, pick K non-adjacent positions to maximize the sum. This is solved in O((N+K) log N) using a max-heap with a doubly-linked-list "undo" technique (each pop removes the chosen element and its neighbors, inserting a virtual "undo" element with value left+right−center). We run this for all three sortings and take the maximum answer. Total complexity is O(N log N) per test case, well within limits since the sum of N across test cases is ≤ 10⁵.
