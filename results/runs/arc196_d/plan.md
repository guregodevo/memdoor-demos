### PLAN
The key insight is that a set of people is infeasible if and only if some pair within it "conflicts": two same-direction people whose intervals properly cross (max(a_i,a_j) < min(b_i,b_j) and neither strictly contains the other), or two opposite-direction people sharing an endpoint. For each person j we compute prev[j] = the largest index i < j that conflicts with j. Then query [L,R] answers "No" iff max(prev[L+1..R]) >= L. The crossing pairs are found via CDQ divide-and-conquer on the index dimension with a sweep-line + segment tree in the spatial dimension (O(M log M log N)), while endpoint-sharing is O(M) with simple arrays. Range-max queries on prev[] answer each query in O(1) via a sparse table.
